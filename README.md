# Adventure Game
This 2D adventure game was developed using JavaFX by following the [YouTube tutorial series](https://youtu.be/om59cwR7psI) by Ryisnow.

The aim of this project was to understand the fundamentals of game development and explore key concepts such as character movement, animations, inventory management, and AI behaviour.

## Features
- A controllable character with responsive movement, multiple animations (walking, attacking), and the ability to equip different weapons.
- Players can level up, gain experience, and manage an inventory system where items such as weapons, armour, and potions can be equipped or used.
- NPCs with interactive dialogue and monsters with pathfinding and combat abilities to attack the player.
- Multiple levels with different environments and enemies.
